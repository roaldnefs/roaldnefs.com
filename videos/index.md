# Videos

> Recordings of conference talks by Roald Nefs on automotive security, hardware hacking, and AI-assisted vulnerability research.

Recordings of talks I've given at conferences and meetups, newest first. Playing a video loads it from YouTube.


- [Auto's hacken voor beginners: van keyless entry tot CAN-bus exploits](https://www.youtube.com/watch?v=HH47sE9umsA) (EHGN, May 2026): A Dutch-language session on car hacking with cheap hardware: rolljam and relay attacks on keyless entry, and spoofing CAN frames on an instrument cluster.
- [Revving Up with Java: A Beginner's Journey into Automotive Hacking](https://www.youtube.com/watch?v=ujLLlRNcvJ8) (NLJUG, December 2025): An introduction to automotive security for Java developers: how vehicle networks work, and sending, receiving and analysing CAN bus messages from Java.
- [Teaching AI to Hunt for Vulnerabilities](https://www.youtube.com/watch?v=ii90UM4S5B0) (pyGrunn and aiGrunn, December 2025): How Truffler, an experimental tool built on large language models, explores software like a curious ethical hacker, with a human steering the hunt.
- [Python on Wheels: Hacking Automotive Systems](https://www.youtube.com/watch?v=Wnn3krHydwE) (pyGrunn and aiGrunn, June 2025): Using Python to get into vehicle networks, analyse their security flaws, and build defences for cars that are networks of software and hardware.
- [Pwning your Java service](https://www.youtube.com/watch?v=nlmlmfh0YHw) (NLJUG, January 2025): Security from a breaker's point of view: step-by-step demonstrations of how attackers exploit Java web applications, and how to defend against them.
- [An Introduction to Hardware Hacking using Python](https://www.youtube.com/watch?v=s22WKWZO1Eg) (pyGrunn and aiGrunn, June 2024): A primer on hardware hacking with Python, covering GPIO control, radio communication and talking to sensors, with examples and demonstrations.
